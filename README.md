# Borozdov Primer

A theme from the Borozdov collection. Two faces — light **Handout**, a cream-paper magazine
for learning, and dark **Seminar**, the same pages under a violet-black evening. Violet-
black ink, square corners, butter sticker buttons and deep teal blocks.

![Borozdov Primer in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/primer/main/screenshots/light.png)

![Borozdov Primer in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/primer/main/screenshots/dark.png)

## Principles

- **Square corners everywhere.** Buttons, tags, fields, cards and tables are sharp; white
  cards are drawn by a 1px violet-black rule, never a soft shadow.
- **Butter is the raised voice.** The main button is a butter sticker with a hard offset
  shadow; butter also marks a checked task, the open file and the highlighter.
- **Deep teal blocks.** The plain note is a teal block with cream text and a butter title;
  table headers are a teal band.
- **One geometric voice.** Mint Spirit No2 Bold for the title and the two largest headings;
  hierarchy by scale, not tracking.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as white cards inside a violet-black rule; the plain note is a deep teal block
- Tables with a violet-black frame and a teal header band
- Tags as square labels that turn butter under the pointer
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Primer**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/primer/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Primer/`, then choose Borozdov Primer under Settings →
Appearance → Themes.

## Font

Mint Spirit No2 Bold (© Arkandis Digital Foundry) is embedded in `theme.css` as base64 WOFF2
under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). One weight,
Latin and Cyrillic, for the title and the two largest headings only.
